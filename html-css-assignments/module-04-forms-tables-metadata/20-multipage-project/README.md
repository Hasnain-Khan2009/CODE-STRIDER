# Assignment 20 — Multi-page HTML Project

Pages: `index.html` (Home) · `about.html` · `registration.html` · `contact.html`

- Pure HTML (no CSS yet). Styling is added in Assignment 25 (`module-05-css-fundamentals/25-styled-multipage`).
- Every page shares the same `<header>`, `<nav aria-label="Main">` (with `aria-current="page"` on the active link) and `<footer>`.
- Uses: headings, lists, links, tables, forms (text, email, tel, date, radio, checkbox, select, number, textarea, password), semantic landmarks and full meta tags.

Open `index.html` with Live Server and click through all four pages.
