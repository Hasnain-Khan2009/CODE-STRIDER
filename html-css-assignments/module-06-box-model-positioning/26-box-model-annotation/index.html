The CSS Box Model, explained on my own element

Open DevTools (F12), pick the blue box below and compare the numbers.

1. The element

My box
.box {
  width: 240px;       /* content */
  height: 80px;       /* content */
  padding: 20px;      /* space inside the border */
  border: 4px solid;  /* the edge */
  margin: 30px;       /* space outside the border */
}

3. The arithmetic

Total space the element occupies (with box-sizing: content-box)
PartCalculationResult
Visible width240 + (20 × 2) + (4 × 2)288px
Visible height80 + (20 × 2) + (4 × 2)128px
Width including margin288 + (30 × 2)348px
Height including margin128 + (30 × 2)188px

With box-sizing: border-box the width includes padding and border, so width: 240px would give a box that is exactly 240px wide. That is why most stylesheets start with *, *::before, *::after { box-sizing: border-box; }.
