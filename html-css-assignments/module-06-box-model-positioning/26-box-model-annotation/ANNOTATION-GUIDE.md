# Assignment 26 — Annotate a screenshot of the box model

> ⚠️ The assignment asks for a **screenshot of one of your own elements**. Take it yourself (steps below) and save it as `box-model-annotated.png`. `index.html` already contains a complete annotated diagram you can use as your reference.

## Steps
1. Open `index.html` with Live Server.
2. Press **F12** → **Elements** tab → click the blue `.box` element.
3. Open the **Computed** tab: the coloured box-model diagram shows margin (orange), border (yellow), padding (green) and content (blue).
4. Take a screenshot of the page and of the DevTools diagram (`Win + Shift + S` on Windows, `Cmd + Shift + 4` on macOS).
5. Annotate with Paint / Snip & Sketch / Preview / Canva: add arrows and labels for **content, padding, border, margin** and the total width.
6. Save as `box-model-annotated.png` in this folder and commit it.

## Explanation to write below your screenshot (edit with your own numbers)
- **Content** — 240 × 80px: where text and images live.
- **Padding** — 20px on all sides: breathing room inside the border; takes the background colour.
- **Border** — 4px solid teal: the visible edge.
- **Margin** — 30px: transparent space that pushes neighbouring elements away; vertical margins of siblings can *collapse*.
- **Total visible size** — 240 + 40 + 8 = **288px** wide; including margin **348px**.
