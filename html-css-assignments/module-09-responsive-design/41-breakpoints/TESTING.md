# Assignment 41 — Multi-screen Testing Record

> ⚠️ Testing has to be done in **your** browser. Tick the last column after you check each row, and add a screenshot or two in a `screenshots/` folder.

## How to test
1. Open `index.html` with Live Server.
2. Press **F12** → click the **device toolbar** icon (or `Ctrl + Shift + M`).
3. Choose each size below (use *Responsive* mode for custom widths) and visit all four pages.
4. Look for: horizontal scrollbar, cut-off text, overlapping elements, buttons that are hard to tap.
